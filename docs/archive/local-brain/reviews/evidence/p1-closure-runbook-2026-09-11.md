# Local Brain P1 收尾：外部门控验收 runbook（草稿）

> 用途：44 项 `unverified` 验收里有 5 组卡在外部条件上，代码侧无法自证。本文件给出**你要执行的操作、要留的证据、判据**，以及我回写状态的位置。
> 回写目标：`docs/reviews/personal-brain-correctness-acceptance.md`（逐行状态）与证据目录 `docs/reviews/evidence/`。
> 原则：局部测试通过 ≠ AC 通过；未执行的项保持 `unverified`，不用"代码已实现"替代证据。

## 通用准备

- 应用：`cd apps/screenpipe-app-tauri && bun run dev:tauri`（日常闭环）或 `bun run build:tauri:dev`（一次性测试包）
- 数据隔离：`SCREENPIPE_DATA_DIR=<目录>` 指到独立目录，别用日常库做破坏性项
- 模型：设置页「模型与密钥」选定预设（记录 preset / provider / model id 到证据）
- 证据格式：每项留 `时间 + 操作 + 原始输出（REST/JSON/日志行）+ 截图或录屏`，存到 `docs/reviews/evidence/p1-closure-<date>/`

## S1 真实语料与质量集（13 项）

覆盖：AC-R1-01/02/03/04、AC-R2-01/02/03、AC-R3-01/02/03、AC-R4-01、AC-R5-01/02/03、AC-EVAL-01..04、AC-R12-01/02。

1. **冻结语料**：挑 ≥10 个真实开发会话，其中 ≥3 个是同一流程的不同实例（例如同一套"改需求→改代码→验证"流程）；导出这些时间窗的间隔与证据清单（`/activity-intervals`、`/activity-intervals/:id/evidence`）。
2. **跑一遍摘要与提取**（活动层落地后）：等待 Summarize/Extract 任务消化完，记录每个间隔的摘要与 WorkUnit。
3. **人工核对**（这是判据的实际来源）：
   - ≥80% 间隔产出合法 WorkUnit（AC-R1-01）
   - ≥90% 事实字段有证据支持（AC-EVAL-02）
   - SOP 可用性人工确认（AC-R2-01）
4. **保留集问答**：冻结 30–50 条查询（问题 + 期望引用），跑问答，记录：无依据结论数（要求 0）、可回答率（要求 ≥80%）、引用是否正确指向版本（AC-EVAL-03、R7-01 已过，R12-02 需从知识库入口再走一遍）。
5. **纠错闭环**：v1→v2 修订、废止、到期复核的真实 UI 演示（AC-R2-02/03、EVAL-04）。

判据：以上四项阈值达标 + 保留集无依据结论为 0。回写：EVAL-01..04、R1-01..04、R2-01..03、R5-01..03。

## S2 办公账号接入（5 项）

覆盖：AC-R9-01/02/03/04、AC-EVAL-07（含 AC-R6-01 的办公派生清理线）。

1. 连接页真实授权飞书 / 腾讯会议，记录 scope 与账号类型（AC-R9-04）。
2. 导入真实内容：≥10 会话，检查导入率 ≥90%、中文检索命中、跨工具链路 WorkUnit→SOP→问答→删除（AC-R9-01/03）。
3. 异常路径：依赖缺失、权限不足、限流、离线、断开/取消同步（AC-R9-02）。
4. 腾讯会议真实转写的时间回链（AC-EVAL-07）。

判据：导入率与链路可复现，异常路径不产生假成功。回写：R9-01..04、EVAL-07。

## S3 桌面真机流程（约 15 项）

覆盖：AC-R6-02/03/04、AC-R7-02、AC-R8-01/02/03、AC-R11-01/02/03、AC-R12-03、AC-R13-01..05。

1. 生命周期：关窗、退出、休眠、断网、非法输出、预算耗尽下的任务真实状态（AC-R8-01）。
2. 取消/删除：长批运行中取消、删除来源后消息与正文清理（AC-R8-02、R7-02、R12-03）。
3. 触发器：手动/定时/事件三种触发 + 重启/失租约/超时（AC-R13-02）。
4. 资源竞争：聊天 + Brain + 用户 Pipes + 两平台同步并跑（AC-R13-03）。
5. 旧机制切换：四类旧机制迁移、崩溃/回滚、旧 API 兼容（AC-R13-04）。
6. 界面与文案：启动/引导/错误/空状态逐屏核对；品牌残留扫描（AC-R11-01/02/03）。

判据：每项留录屏或截图 + 对应 DB/日志佐证。回写：R6、R7、R8、R11、R12、R13 各行。

## S4 5 工作日观察（2 项）

覆盖：AC-EVAL-05、AC-EVAL-06。

- 固定实际 Preset/Runtime 与出口（Pi / 文件 / MCP），连续 5 个工作日只观察不干预：每日记录审核负担（处理条数/耗时）、积压量、出口是否可用可观测。
- 判据：无人工救济仍可运转；积压与负担曲线可解释。
